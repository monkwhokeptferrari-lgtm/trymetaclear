What Midjourney stores inside your images

When you download an image from the Midjourney website, the file keeps a written record of how it was made. Anyone who opens it in a metadata viewer can read it. These are the fields you will usually see:

Field Example content Why it matters
Description Full prompt, e.g. neon city at dusk --ar 16:9 --v 6, followed by the Job ID Shows your exact prompt and settings to anyone with the file
Job ID A unique ID such as 3f2a…-… Links the file back to the job and, unless Stealth Mode is on, its public gallery page
Author Your Midjourney username Ties the image to your account
Digital source type / creation time trainedAlgorithmicMedia, timestamp Marks the file as AI-generated and records when it was made

Exact fields vary by Midjourney version and by how the image was saved. The scan above lists exactly what is in your file.

Why remove Midjourney metadata?

  • Keep your prompts to yourself. A prompt that took hours to refine can be copied in seconds from the Description field.
  • Keep your account private. The Author field and Job ID link a shared file back to you.
  • Deliver clean files to clients. Clients receive the artwork without your working notes and settings.

Removing metadata does not change your obligations. If a platform, client or law requires you to say an image was made with AI, you still need to say so.

Midjourney metadata FAQ

Does Midjourney save my prompt inside the image file?

Yes. Images downloaded from Midjourney usually include a Description field containing the full prompt, the parameters you used (such as --ar or --v) and the Job ID. Many files also have an Author field with your Midjourney username.

Can other people read my Midjourney prompt from the file?

Yes. Anyone with a free metadata viewer such as ExifTool can read the Description and Author fields. Removing the metadata before you share the file stops this.

Is removing the metadata enough to keep my prompt private?

It keeps the prompt out of the file you share. However, unless you use Stealth Mode, images you create can also appear in your public Midjourney gallery, where the prompt is visible. The Job ID links the file to that page, so remove it too.

Will removing Midjourney metadata reduce image quality?

No. Only the metadata is removed. The image data is not decoded or re-compressed, so resolution and quality are unchanged.

Is my uploaded image stored?

No copy is kept. The file is processed in server memory and deleted as soon as the cleaned version is sent back to you.
