What the PDF Metadata Remover removes

Who made it, and with what

The author name, and the app and software that created and saved the file (for example Microsoft Word and Adobe PDF Library), from both the document properties and the hidden XMP data.

When, and how it changed

Created and last-edited dates, document IDs, and the editing history and private app data that tools such as Acrobat leave inside the file. Earlier saved versions, which can still hold deleted text, are discarded too.

Signatures, photos and AI labels

Digital signatures (signer name and signing date), comment author names, the camera details and GPS location inside photos in the PDF, and C2PA Content Credentials that label AI content.

Why PDF metadata matters

Every PDF carries details you never typed. Open a contract, CV or report in any PDF reader's Document Properties and you'll usually see the author's name as it appears on their computer account, the program that made the file, and exactly when it was created and last edited.

That's not all. A hidden XMP block can repeat the same details along with a permanent document ID that links every copy of the file together. Acrobat and other editors may store their own private editing data. Files saved with "incremental updates" keep earlier versions inside them, so text you deleted can sometimes be recovered. Photos placed in the PDF can still include the phone model and GPS location they were taken at.

Removing it before you send a file to a client, publish it online or submit an application keeps those details private. If your PDF contains AI-generated images, see also our guide to C2PA Content Credentials.

How to remove the author name from a PDF

The author name usually comes from the account name on the computer that made the file, so it often shows your full name even if you never typed it. There are three ways to get rid of it:

  1. With this tool (any PDF): drop the file above and click Remove Metadata & Download. The author is removed from both places it's stored, the document properties and the hidden XMP data, along with the app, dates and IDs.
  2. In Microsoft Word, before exporting: go to File > Info > Check for Issues > Inspect Document, inspect, then click Remove All next to "Document Properties and Personal Information". Then save as PDF.
  3. In Adobe Acrobat Pro: open File > Properties and clear the Author field. To remove everything else as well, use the Remove Hidden Information or Sanitize Document option in the Redact tools. The free Acrobat Reader can show these fields but can't edit them.

Clearing only the Author field in File > Properties often leaves the same name in the XMP data, which is why a full metadata remover is the safer option.

How to view a PDF's metadata

  • This tool: drop the PDF above to see every hidden field, including XMP history, signatures, photo GPS and C2PA, before you decide what to remove.
  • Adobe Acrobat Reader: File > Properties (Ctrl+D, or Cmd+D on a Mac) shows the title, author, app, producer and dates.
  • Chrome or Edge: open the PDF in the browser, then choose Document properties from the viewer's menu.
  • Mac Preview: Tools > Show Inspector (Cmd+I) shows the basic document info.

Built-in viewers only show the document properties. They don't show XMP editing history, earlier saved versions, or the metadata of photos inside the PDF.

What the Creator and Producer fields mean

Most PDFs name the app that created them (Creator) and the software that wrote the file (Producer). The values are often cryptic. Here's what the common ones mean:

These fields describe the software, not who wrote the content. A PDF written by a person and one drafted with an AI assistant can carry exactly the same values. To check a file for AI labels, use the AI PDF Detector or the AI Resume Detector.

What it can't remove

  • Visible content: names, addresses or dates typed on the page, in headers and footers, or inside scanned pages are part of the document itself.
  • Valid signatures: any change to a signed PDF breaks its signature, so signature details are removed rather than kept. Keep the original if you need the signed copy.
  • Password-protected PDFs: remove the password in your PDF reader first, then clean the file.
  • Other attachments: files attached inside the PDF are left as they are (only C2PA manifests are removed).

PDF metadata frequently asked questions

Is my PDF uploaded to your server?

No. The PDF tool reads and cleans the file inside your browser, so the PDF never leaves your device. That is different from our image and video tools, which process files on our server.

What metadata does the PDF Metadata Remover remove?

The author, the app and software that created and saved the file, created and modified dates, document IDs, XMP data, editing history and private app data, earlier saved versions, digital signature details, comment author names, EXIF and GPS data in photos inside the PDF, and C2PA Content Credentials.

Will cleaning change how my PDF looks?

No. Pages, text, images, fonts, links and form fields stay the same. Only hidden metadata is removed, and photos keep their original pixels because only their metadata segments are dropped.

What happens to digital signatures?

They are removed, including the signer name and signing date. Any change to a signed PDF breaks its signature, so a cleaned file can never stay validly signed. If you need the signed version, keep the original.

Can this tool tell if a PDF was made with AI?

Only if the file says so. It flags C2PA Content Credentials and AI references in the XMP data or in photos inside the PDF. Most AI assistants don't add any label when they export a PDF, so a missing label doesn't prove a person made the file.

How do I remove the author name from a PDF?

Drop the PDF into the PDF Metadata Remover and click Remove Metadata & Download. The author is removed from both the document properties and the hidden XMP data. If you write in Word, you can also run File > Info > Check for Issues > Inspect Document before exporting.

How can I see a PDF's metadata?

Drop the PDF into this tool to see everything it contains. In Adobe Acrobat Reader, File > Properties (Ctrl+D) shows the title, author, app and dates, but not the XMP history, photo GPS or C2PA data.

What can't it remove?

Anything that is part of the visible content, such as a name typed on a page, a header or footer, or text in a scanned page. It also doesn't open password-protected PDFs; remove the password first.
