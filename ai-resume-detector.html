    How to check a resume PDF for AI labels in 3 steps

    1. Add the resume: Select or drop the resume PDF into the box. It is read in your browser and is not uploaded.
    2. Read the verdict: See whether the file's data says AI was involved, including AI-labelled headshot photos, with the evidence for each signal.
    3. See what it reveals: Check which app or resume builder made the file, and remove hidden details with the PDF Metadata Remover if you're the author.

    What the AI Resume Detector looks for in a resume

    • AI-generated headshots: some AI photo tools add C2PA Content Credentials or an IPTC "AI generated" field to the image, and it can stay in the photo after you place it in your resume.
    • An AI tool named as the creator: if the PDF was exported by an app that names itself (for example ChatGPT or Copilot) in the Creator or Producer field.
    • AI markers in the hidden XMP data: the standard IPTC source type that apps write for AI-generated content.
    • What made the file: Word, Google Docs, Canva, a resume builder or an automated converter, explained in plain English.

    What a recruiter can see in your resume file

    Anyone who opens your resume in a PDF reader can check File > Properties. Depending on how you made it, that can show:

    • Author: often the account name on your computer, or a previous owner's name if you started from someone else's template.
    • App: Word, Google Docs, Canva, a resume builder or an online converter.
    • Created and modified dates: when the file was made and last changed.
    • Title: sometimes an old file name such as "Resume_final_v7" or the name of a template.

    None of this is wrong to have, but you can choose what you share. Drop your resume into the detector above to see exactly what it carries.

    Resume file checklist before you apply

    1. Check the file with the AI Resume Detector above.
    2. If it shows an old author name, a template title or details you'd rather not share, clean it with the PDF Metadata Remover.
    3. If you used an AI headshot and it's flagged, decide whether to keep it, disclose it, or use a real photo.
    4. Give the file a clear name, such as Firstname-Lastname-Resume.pdf.
    5. Open the final PDF on your phone to check the layout before you send it.

    For recruiters: how to read the result fairly

    • "AI signals found" means the file itself declares AI, for example an AI-labelled headshot or a document made with an AI tool. It doesn't tell you how much of the writing came from AI.
    • "No AI signals in the file" doesn't prove a person wrote it. AI assistants rarely label the PDFs they export.
    • Don't reject candidates on this alone. Many people use AI to polish wording, just as they use spell checkers. Judge the experience and skills, and ask about them in the interview.

    We deliberately don't show an "AI-written %" score. Tools that guess from writing style are unreliable and tend to flag non-native English speakers and people who write formally.

    AI Resume Detector frequently asked questions

    Can this tell if a resume was written with ChatGPT?

    Only if the file says so. It checks the resume's file data for AI labels, AI tool names and AI-labelled images. It doesn't judge the writing, because AI-writing detectors are unreliable and often flag real candidates.

    Should recruiters reject a resume based on this result?

    No. An AI signal shows the file declares AI involvement, such as an AI-generated headshot, not how the candidate wrote their experience. A clean result doesn't prove a person wrote it either.

    Will employers know I used AI on my resume?

    Not from the file's data in most cases, because AI assistants rarely label PDFs. An AI-generated headshot can carry an AI label, and the file may name the app or resume builder you used.

    Is my resume uploaded?

    No. The AI Resume Detector runs entirely in your browser, so the resume never leaves your device.

    Can recruiters see who made my resume PDF?

    They can see whatever the file stores. Anyone can open File > Properties in a PDF reader to see the author, the app that made it and its dates. Use the PDF Metadata Remover if you'd rather not share them.

    Does an AI-generated headshot show up as AI?

    It can. Some AI image tools add C2PA Content Credentials or an IPTC "AI generated" field to the photo, and that label can stay in the image when you add it to a PDF, unless the app you used removed it. The detector flags it when it's there.

    How do I remove hidden data from my resume?

    Use the free PDF Metadata Remover. It removes the author, software, dates, document IDs, photo details and AI labels without changing how the resume looks.
