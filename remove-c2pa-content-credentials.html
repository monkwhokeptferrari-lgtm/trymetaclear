Important Scope & Limitations

C2PA markers exist inside file header blocks. Removing C2PA manifests strips software claims (such as ChatGPT, DALL-E, Adobe Firefly, or Midjourney provenance signatures). However, header stripping does not modify invisible pixel-level watermarks (such as Google DeepMind SynthID), as pixel watermarks are structural image matrix modifications rather than file header tags.
