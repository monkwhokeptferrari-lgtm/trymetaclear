What metadata is inside a DALL-E or ChatGPT image?

Since early 2024, OpenAI has attached C2PA Content Credentials to images generated with DALL-E 3, and it has continued this with ChatGPT's newer image models. C2PA is an open standard backed by Adobe, Microsoft, the BBC and others. It lets a file carry a signed record of where it came from. Here is what you will typically find when you scan one of these files:

Field Where it is stored What it tells people
C2PA manifest A JUMBF block (a caBX chunk in PNG, an APP11 segment in JPEG) The image was signed by OpenAI and has not been changed since
Actions Inside the C2PA manifest How the file was produced, for example c2pa.created
Digital source type C2PA assertion or IPTC/XMP trainedAlgorithmicMedia, the standard label for AI-generated media
Signature and certificate Inside the C2PA manifest Who issued the credential, so viewers like contentcredentials.org can verify it

Unlike Midjourney or Stable Diffusion, OpenAI does not normally write your prompt into the file. If you need to remove prompt text, it was probably added by another app; see our Midjourney metadata guide or the general C2PA removal guide.

How to remove DALL-E metadata

  1. Upload the image. Drop the PNG, JPG or WebP you downloaded from ChatGPT or the OpenAI API into the box above.
  2. Review the scan. Fields that point to AI generation, such as the C2PA manifest and digital source type, are tagged so you can see them at a glance.
  3. Download the clean copy. Click "Remove Metadata & Download". You get the same image with the metadata blocks removed.

To check that it worked, upload the cleaned file again. The scan should show no C2PA fields. You can also drop it into the Content Credentials verify tool at contentcredentials.org. It should report that no credentials were found.

What removing metadata does not do

  • It does not alter pixels, so invisible watermarks and fingerprints, if present, are untouched.
  • Some provenance systems store a copy of the manifest online and can match it to the image later ("durable" Content Credentials). Removing the local copy does not delete that record.
  • It does not change the rules you are under. If a platform, client or local law requires you to disclose AI-generated content, you still need to do so.

The most common reasons people clean these files are tidy client deliverables, consistent metadata across a portfolio, and not publishing tool or account details they did not mean to share.

DALL-E & ChatGPT metadata FAQ

What metadata do DALL-E and ChatGPT add to images?

Images from DALL-E 3 and ChatGPT's image generation carry a C2PA Content Credentials manifest. It names OpenAI as the signer, records that the image was created by an AI model, and is protected by a cryptographic signature. The file may also carry an IPTC digital source type of trainedAlgorithmicMedia, which is the standard label for AI-generated media.

Does DALL-E save my prompt inside the image file?

Usually not. OpenAI's manifest describes how the image was made, not what you typed. If you find prompt text in a file, another app or editor most likely added it. Scan the file above to see exactly which fields it contains.

Will removing the metadata change how the image looks?

No. Only the metadata blocks are removed. The pixel data is copied as-is and never re-compressed, so resolution, colors and file format stay the same.

Does this remove every sign that an image was made with AI?

No. TryMetaClear removes metadata stored in the file. It does not change the pixels, so it does not affect invisible watermarks, fingerprint matching, or visual AI detectors.

Is my uploaded image stored anywhere?

No copy is kept. The file is processed in server memory and deleted as soon as the cleaned version is sent back to you.
