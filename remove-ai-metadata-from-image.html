How to Remove AI Metadata & Stop AI Labels on Images (4 Methods)

AI generators and editing apps embed prompts, model names, and C2PA credentials into your files—triggering automated AI flags on Instagram and Facebook. This guide covers four ways to strip them, what each method misses, and how to clean your photos instantly for free.

What counts as "AI metadata"?

Different generators leave different traces. These are the four you will run into most:

  • C2PA Content Credentials: a signed manifest added by DALL-E 3, ChatGPT, Adobe Firefly and others. Learn more about C2PA.
  • IPTC digital source type: the value trainedAlgorithmicMedia, the industry label for AI-generated media.
  • Prompt and settings text: Midjourney stores the prompt and Job ID; Stable Diffusion tools such as Automatic1111 and ComfyUI store prompts, seeds, samplers and even whole workflows in PNG text chunks. See the Midjourney guide.
  • Software and creator fields: EXIF/XMP fields naming the app, model or account.

Method 2: ExifTool (command line)

ExifTool is the free, open-source program that TryMetaClear uses behind the scenes. If you are comfortable with a terminal, this command removes all writable metadata from a file:

exiftool -all= -overwrite_original image.png

It is fast and works well in batch scripts. Two things to watch for: older ExifTool versions do not remove C2PA blocks from every format, and -overwrite_original replaces your file without a backup. Run exiftool -a -G1 image.png afterwards to confirm nothing is left.

Method 3: Screenshot or re-export the image

A screenshot creates a new file without the original metadata. The trade-off is quality: the screenshot is limited to your screen resolution, can be scaled or cropped, and adds its own metadata (device, time, sometimes the screenshot app).

Re-exporting from an editor is similar, but be careful. Adobe Photoshop and other editors can add new Content Credentials on export when that setting is on, and most exports re-compress JPEGs.

Method 4: Built-in Windows and macOS options

Windows: right-click the file → Properties → Details → "Remove Properties and Personal Information". macOS: open the image in Preview → Tools → Show Inspector, where you can remove location data.

These options only handle common EXIF fields such as camera, date and GPS. They do not remove C2PA manifests, PNG text chunks (where prompts are stored), or most XMP fields, so they are not enough for AI images.

Frequently asked questions

How can I tell if an image has AI metadata?

Upload it to a metadata scanner such as the one on this page. Look for a C2PA manifest, an IPTC digital source type of trainedAlgorithmicMedia, a Software field naming an AI tool, or text fields that contain a prompt and generation settings.

Is taking a screenshot enough to remove AI metadata?

A screenshot drops the original metadata, but it usually lowers resolution, may crop or rescale the image, and adds new screenshot metadata of its own. Removing the metadata directly keeps the original pixels.

Which image formats are supported?

The tool on this page accepts PNG, JPG, WebP and HEIC images up to 100 MB.

Does removing metadata make an AI image undetectable?

No. It removes information stored in the file. Invisible watermarks such as SynthID, fingerprint matching and visual AI detectors work on the pixels, which are not changed.
